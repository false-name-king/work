# Work Attendance & Production Reporting System

一个为生产班组设计的移动端考勤与产量数据报表管理系统。

## 项目简介

该系统旨在简化工厂班组或工作小组的每日考勤记录与产量统计流程。通过直观的 iOS 风格界面，组长（机长）可以快速记录组员的出勤状态、分配机台、统计生产批次与件数，并一键生成标准化的文本报表以便在社交软件中分享。

## 主要功能

- **📱 移动端优先设计**：采用 iOS 风格的毛玻璃效果与简洁卡片布局，适配移动设备操作。
- **📊 数据统计与管理**：
  - 记录组员出勤状态（出勤、请假、公休、产假等）。
  - 统计个人及全组的生产数据（批次、件数）。
  - 设置并记录组员的工作内容与机台分配。
- **⏰ 工时追踪**：精确记录组员的加班或工作起止时间。
- **📝 灵活备注**：支持添加大批量任务或奖金情况的全局备注。
- **📋 一键分享**：支持一键生成并复制“生产报表”与“工时表”，方便在微信/钉钉群组内快速上报。

## 技术栈

- **框架**: React 19 + TypeScript
- **构建工具**: Vite
- **状态管理**: Zustand
- **样式**: Tailwind CSS + Radix UI
- **图标**: Lucide React
- **日期处理**: Dayjs
- **提示组件**: Sonner

## 快速开始

### 安装依赖

```bash
npm install
# 或
pnpm install
```

### 开发环境

```bash
npm run dev
```

### 构建部署

```bash
npm run build
```

## 项目结构

- `src/components/ui`: 基于 Radix UI 封装的基础组件。
- `src/pages`: 核心业务页面（数据统计、日期管理）。
- `src/store`: 使用 Zustand 管理的全局数据中心。
- `src/assets`: 项目静态资源。
